规则

名单模式

每日限额

单位是分钟。填 0 = 这天完全不开,留空 = 这天不限时间。

每周限额

单个 app 限额

单位是分钟。填 0 = 这个 app 完全不开,留空 = 不单独限制, 但用掉的时间照样算进每日总额。单个 app 的限额比每日总额先判定。

禁用时段

连不上这台 Pi 的时候

保存要过一次 Face ID。电视最多 30 秒内生效。

等待审批

注册审批手机之后,改规则不会立刻生效 —— 要在审批 App 上用 Face ID 确认一次。

离线应急码

Pi 连不上的时候,用遥控器把这个码输进电视就能解锁 30 分钟。

审批手机

iPhone 的 passkey 在人脸识别失败时会退回手机密码,所以它只能当登录用。注册一台审批 手机之后,下发解锁和关闭拦截都要用审批 App 的 Face ID 签名 —— 知道手机密码也没用。
